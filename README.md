# Ciclo Pull · Push · Pierna

App para llevar el registro del gimnasio: muestra la sesión que sigue, propone el peso de hoy, cuenta los descansos y guarda el progreso. Se instala en el teléfono y funciona sin señal.

Para usarla, abre la dirección de GitHub Pages de este repositorio en el teléfono y toca **Instalar**.

Los registros se guardan en el teléfono. Desde Progreso se puede enviar o descargar una copia de seguridad.
